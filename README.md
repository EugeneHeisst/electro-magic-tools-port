# Electro-Magic Tools PORT

Неофициальный порт **Electro-Magic Tools 1.2.6.2** (fewizz, TheSilentium; оригинальный проект Tombenpotter) на **Minecraft 1.21.1 / NeoForge 21.1.256**. Версия **0.1.10**.

Перенесены 21 солнечная панель, пять эссенциальных генераторов, зарядная станция жезлов и эфирный переработчик; электрические инструменты, очки, броня, крылья, кольца, шесть фокусов и их сущности; Мьёльниры и стражи, переносной узел, электрическое облако, UU-рецепты и исследования. Используются настоящие энергосеть IC2, банки/жезлы/верстак/тигель/инфузия/исследования/Baubles Thaumcraft. Восстановлены 79 магических рецептов и 57 исследований оригинала; есть конфиги отключения исследований с зависимостями.

В версии 0.1.9 исправлены защита каждого блока мотыги, оплата и дроп пил/омниинструментов и характеристики таумиевых крыльев. Возвращены `/emt_outputs` с настоящей книгой актуальных значений EU и оригинальные звуки холостого хода/остановки пил. Три перекрывавших друг друга UU-рецепта оригинала разделены по осколкам: земля → смола, огонь → красная пыль, вода → лазурит.

В версии 0.1.10 кольцо больше не сохраняет бессмертие Creative/Spectator после перехода в Survival и снятия. Штрафы крыльев от воды и дождя снова складываются отдельно, как в оригинале; проверены настоящая вода, дождь и их сочетание у берега.

## Зависимости и сборка

Java 21, **IC2 PORT 0.1.23**, **Thaumcraft PORT 0.17.178**. **ASP PORT 0.1.2** включён в стенд разработки; JEI необязателен. Версии архивных зависимостей заданы в `gradle.properties`, пути — в `build.gradle`.

Сборка: `./build.sh`, результат `build/libs/electro-magic-tools-modern-0.1.10.jar`. Архивы JAR, логи и скриншоты — `versions/<version>/`.

## Проверки

`JAVA_HOME=/usr/lib/jvm/java-21-openjdk JAVA_TOOL_OPTIONS=-Demt.audit=server ./gradlew runServer -q` запускает изолированный сервер на порту 25583. `./audit-client.sh -PwithJei=true` — скрытый беззвучный клиент с отдельным миром EMTAudit. `./mp-flight-audit.sh` проверяет полёт при allow-flight=false с контрольным отключением сброса счётчика.

431 серверная проверка, все 82 модели, родные страницы книги/JEI, книга команды и жизненный цикл звуков проверены. Общий сервер с остальными портами и набором модов: 29 проверок, клиент с JEI: 14. Звуковой аудит использует NoOutput; фактическое прослушивание не входило в скрытые проверки. Подробности — [CODEX_HANDOFF.md](CODEX_HANDOFF.md).
